SPLDV - Gita

Permisalan:
x = Harga Jam Dinding
y = Harga Hiasan Dinding

Bentuk SPLDV:
2x + y = 150.000 ... (1)
2x + 3y = 150.000 ... (2)

Penyelesaian - Eliminasi y:
2x + y = 150.000 | x3 | 6x + 3y = 450.000
2x + 3y = 270.000 | x1 |2x + 3y = 270.000
________________________________ -
4x = 180.000
x = 180.000 ; 4
x = 45.000

Substitusi x = 45.000 ke persamaan (1):
2x + y = 150.000
2 (45.000) + y = 150.000
90.000 + y = 150.000
y = 150.000 - 90.000
y = 60.000

Kesimpulan: Harga 1 Jam Dinding = Rp75.000, Harga 1 Hiasan Dinding = Rp45.000

SPLDV - Haqqi

Permisalan:
x = Lampu Hias dari CD
y = Tas Tangan Bulat dari Kabel

Bentuk SPLDV:
2x + y =175.000 ... (1)
3x + 2y = 300.000 ... (2)

Penyelesaian - Eliminasi y:
2x + y = 175.000 | x2 | 4x + 2y = 350.000
3x + 2y = 300.000 | x1 | 3x + 2y = 300.000
________________________________ -
x = 50.000

Substitusi x = 50.000 ke persamaan (1):
2(50.000) + y = 175.000
100.000 + y = 175.000
y = 175.000 - 100.000

y = 75.000

Kesimpulan: Harga 1 Lampu Hias dari CD = Rp50.000, Harga 1 Tas Tangan Bulat dari Kabel = Rp75.000

SPLDV - Ashfa

Permisalan:
x = Hiasan Dinding (keyboard Art)
y = Lampu Tidur

Bentuk SPLDV:
x + 2y = 175.000 ... (1)
2x + y = 200.000 ... (2)

Penyelesaian - Eliminasi y:
x + 2y = 175.000 | x2 |2x + 4y = 350.000
2x + y = 200.000 | x1 | 2x + y = 200.000
________________________________ -
3y = 150.000
y = 150.000 : 3

y = 50.000

Substitusi xy = 50.000 ke persamaan (1):
x + 2(50.000) = 175.000
x + 100.000 = 175.000
x = 175.000 - 100.000

x = 75.000

Kesimpulan: Harga 1 Hiasan Dinding (Keyboard Art) = Rp 75.000, Harga 1 Lampu Tidur = Rp 50.000
